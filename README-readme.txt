更新包 — 產品拖曳排序 ＋ 中文改動提醒
=====================================

這包含兩個功能，第一次上傳請照順序做。

【一】產品自訂排序
1) Cloudflare 後台 → Workers & Pages → D1 → 你的資料庫 → Console
   貼上 db/v12-product-sort.sql 的內容執行。
   （或 npx wrangler d1 execute <DB名稱> --remote --file db/v12-product-sort.sql）

2) 上傳下面的檔案，等 Pages 部署完成。

3) 後台「產品資料」每列左邊會出現拖曳握把與順序編號（001、002…）。
   按住整列拖曳，放手自動存檔。手機用右側的 ↑ ↓ 按鈕。

【二】中文改了 → 跳框一起改其他語言
不需要動資料庫，上傳檔案即可。

觸發時機：在「繁體中文」頁籤改了可翻譯的欄位並按儲存。
  · 介面文字 —— 改中文那一條
  · 產品資料／時間軸 —— 產品名稱、重點一句話、產品敘述、產品細項、標題、說明…
跳出的框會列出「舊中文 → 新中文」，底下是各語言現有的譯文輸入框，
改完按「一起儲存」一次送進資料庫。

三個按鈕：
  一起儲存            中文 + 你改的譯文一起存
  只存中文，稍後再譯   只存中文（原本的行為）
  取消 / Esc          什麼都不存

不會觸發的情況：改圖片、專利號、年份、備註（那些沒有翻譯），
以及新增資料（沒有舊譯文可以對照，請改用「一鍵翻譯」）。
「頁面區塊」維持原本的行為 —— 它存中文後本來就會自動補翻譯。

要上傳的檔案
------------
admin/index.html
functions/api/products.js
functions/api/admin/save.js
functions/api/admin/data.js
db/v12-product-sort.sql（只有【一】需要，跑完就不用留）

注意
----
- 首頁與產品中心的卡片編號（001、002…）與篩選鈕順序會跟著產品順序跑。
- 產品清單的搜尋框有文字時不能拖曳，清空搜尋才會出現握把。
- 備份指令：npx wrangler d1 export <DB名稱> --remote --output backup.sql
