頁面區塊 — 上傳說明
============================================================

做完之後：業務可以在「關於營德」「永續發展」自行新增內容段落。

------------------------------------------------------------
步驟 1｜先跑 SQL
------------------------------------------------------------
D1 Console → 貼上 db/v7-blocks.sql → Execute
（建立 page_blocks 表，只有一張表，不會動到現有資料）

------------------------------------------------------------
步驟 2｜上傳檔案
------------------------------------------------------------
新增：
  db/v7-blocks.sql
  src/page-blocks.js               前端渲染
  functions/api/blocks.js          公開讀取

覆蓋：
  admin/index.html                 多了「頁面區塊」
  about.html                       時間軸之後插入區塊容器
  sustainability.html              行動呼籲之前插入區塊容器
  functions/api/admin/data.js
  functions/api/admin/save.js

------------------------------------------------------------
步驟 3｜試一個
------------------------------------------------------------
後台 → 頁面區塊 → 關於營德 → 新增區塊
  版型選「圖右文左」→ 填標題與內文 → 上傳圖片 → 儲存
開網站的關於營德，捲到製造歷程下面就會看到。

------------------------------------------------------------
五種版型
------------------------------------------------------------
  圖右文左 / 圖左文右   標準圖文並排，最常用
  全寬大圖 + 標題       整排大圖，文字疊在下緣
  純文字段落            只有標題與內文
  引言／數據強調        置中、灰底，用來強調一句話或一個數字

樣式由 src/page-blocks.js 決定，業務只填內容 —— 版面壞不掉。
沒填圖片的圖文版型會自動退化成純文字，不會留一個空格子。

------------------------------------------------------------
多語言
------------------------------------------------------------
每個區塊都有語言頁籤，跟產品一樣。
中文填完，其他語言可以之後再補；沒填的語言會顯示中文。

------------------------------------------------------------
為什麼現有的九個區段沒有轉成區塊
------------------------------------------------------------
關於營德現有的區段包含合作網絡圖（三節點）、sticky 對照排版、
編號能力卡、整段工廠影片 —— 這些是為特定內容做的排版，
用五種通用版型表達不出來，硬轉會讓整頁變成一樣的圖文交錯。

而且那些區段的文字已經可以在「介面文字」修改，
轉成區塊只多了「重新排序」與「整段刪除」兩個很少用的能力，
不值得拿現在的設計去換。
