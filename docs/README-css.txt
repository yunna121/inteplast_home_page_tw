修永續頁 hero 背景圖不見
============================================================

要上傳的檔案（1 個）
------------------------------------------------------------
assets/css/sustainability-redesign.css

原因
------------------------------------------------------------
CSS 裡的 url() 是相對於「CSS 檔案自己」的位置，不是相對於網頁。

這個檔案原本放在 repo 最外層，寫 ./src/圖.png 剛好對。
搬到 assets/css/ 之後，我上一包把它改成 ./assets/img/圖.png，
瀏覽器會解讀成 /assets/css/assets/img/圖.png → 404。

正確寫法是 ../img/圖.png（從 assets/css/ 往上一層再進 img/）。

順便說明為什麼之前查不到：CSS 背景圖 404 不會出現在 Console，
只會在 Network 分頁看到。所以 Console 一直是乾淨的。

另外：hero 右邊那個環保標章圖樣是「故意隱藏」的，
CSS 第 219 行寫了 .hero-mark { display: none }，
註解說明標章已經合成在背景圖裡了 —— 那個不是 bug。

上傳後怎麼確認
------------------------------------------------------------
開 /sustainability，Ctrl + Shift + R 強制重新整理，
hero 那塊應該出現淡綠色的封面圖（中間有環保標章）。
