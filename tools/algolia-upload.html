搜尋索引上傳

把網站的產品資料與規格上傳到 Algolia。Excel 改完、轉出 js 之後，回來按一次上傳即可。

1. 填入金鑰

Application ID 已經先幫你填好。Admin API Key 到 Algolia 後台的 Settings → API Keys 複製；它只留在這個瀏覽器（存在本機），不會上傳到 GitHub，也不會出現在網站上。

Admin API Key 有完整寫入權限，請勿貼到任何公開的地方，也不要放進 repo。

2. 檢查要上傳的內容

讀取的是網站正在用的同一份資料（website-data.js、products-data.js），所以上傳的內容與網站顯示一致。

3. 上傳

上傳會先清空舊索引再全部重寫，所以刪掉的產品不會殘留。同時會套用中文分詞、錯字容錯與欄位權重設定。
