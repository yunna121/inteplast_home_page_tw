產品資料 Excel 工具

新的一本 src/data/products-data.xlsx：只有一張工作表「產品資料」，一列一項產品：產品、英文名稱、產品敘述、產品圖片，外加「重點」欄（想強調的一句話，字會放大）與「產品細項」欄（顯示成膠囊標籤）。去背與否由網頁自動判斷，不用填。

1. 下載 Excel

已帶入現有的七列，直接在上面改字、改圖片檔名即可。存檔位置：src/data/products-data.xlsx

產品網頁上的大字名稱，一列一項
英文名稱名稱上方的英文小字（可留空）
重點想特別強調的一句話，顯示在名稱下方、字比敘述大且加粗（可留空）
產品敘述重點下面那一段
產品圖片只寫檔名＝放在 src/product-img/；找不到會自動改試 src/ 根目錄
產品細項用「、」或逗號分隔，一項一顆膠囊標籤（例：連捲點斷、單張抽取、環保標章認證）；含環保／認證／標章／回收／再生字樣的會自動變綠

2. 改完後轉檔

還沒架伺服器時，網頁沒辦法直接讀本機的 xlsx，所以改完要轉出 products-data.js 覆蓋 src/data/products-data.js。

把 products-data.xlsx 拖到這裡
或點一下選擇檔案
#產品英文名稱重點產品圖片產品細項

更新步驟

  1. 下載 Excel → 重填內容 → 存成 src/data/products-data.xlsx。
  2. 把 Excel 拖到上面的框，確認預覽的列數與內容。
  3. 按 下載 products-data.js，覆蓋 src/data/products-data.js。
  4. 重新整理首頁（Ctrl + F5）。
