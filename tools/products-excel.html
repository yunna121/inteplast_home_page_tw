產品資料 Excel 工具

新的一本 src/data/products-data.xlsx：只有一張工作表「產品資料」，只放產品名稱、產品圖片與產品敘述，沒有規格欄位。 每列一項產品，用「分類」欄區分屬於哪一個產品線。

1. 下載 Excel

已帶入現有資料（六列分類 ＋ 各分類的產品項目），直接在上面重填即可。存檔位置：src/data/products-data.xlsx

類型填「分類」＝首頁六大核心產品那一列；填「產品」＝該分類頁裡的產品項目
分類清潔袋／拉繩袋／蔬果袋／夾鏈袋／其他類／Scale Sheet
產品名稱網頁上的大字名稱
英文名稱名稱上方的英文小字（可留空）
產品敘述名稱下面那一句
產品圖片只寫檔名＝放在 src/product-img/；找不到會自動改試 src/ 根目錄
已去背Y＝去背 PNG，名稱會壓在照片上；N＝白底或實拍方框，文字自動退開不重疊；留空＝自動判斷

2. 改完後轉檔

還沒架伺服器時，網頁沒辦法直接讀本機的 xlsx，所以改完要轉出 products-data.js 覆蓋 src/data/products-data.js。

更新步驟

  1. 下載 Excel → 重填內容 → 存成 src/data/products-data.xlsx。
  2. 把 Excel 拖到上面的框，確認預覽的列數與內容。
  3. 按 下載 products-data.js，覆蓋 src/data/products-data.js。
  4. 重新整理首頁（Ctrl + F5）。
