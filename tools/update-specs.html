還沒有伺服器時，用這個頁面把 website-data.xlsx 轉成網站讀得到的 website-data.js。 改 Excel → 拖進來 → 下載 → 覆蓋檔案，網站的規格表、分類卡片與搜尋同義詞就一起更新了。

更新步驟

  1. 打開 src/data/website-data.xlsx，在自己負責的分類工作表（清潔袋／拉繩袋／…）修改後存檔。
  2. 把存好的 Excel 拖到上面的框，確認預覽的筆數與內容正確。
  3. 按 下載 website-data.js，用下載的檔案覆蓋 src/data/website-data.js。
  4. 重新整理網頁（Ctrl + F5）即可看到新內容。

日後網站架上伺服器後，這個步驟就不需要了 — 網頁會自動直接讀取 Excel， 這份 website-data.js 會退居備援。無論有沒有伺服器，Excel 都是唯一要維護的檔案。
