.header {
  /* 中間欄改成 1fr（最小 0）：選單只拿剩下的空間，不再溢出 */
  grid-template-columns: auto minmax(0, 1fr) auto;
}

.nav-menu {
  justify-self: stretch;      /* 取代 justify-self: center */
  justify-content: center;    /* 選單本身仍置中 */
  padding: 0 8px;
}

.nav-link-item {
  display: inline-block;      /* 原本是 inline-flex：裡面的文字是匿名 flex
                                 item，寬度不夠時不斷行、只溢出，選單就被
                                 壓成一列疊字。inline-block 才會照下面換行 */
  white-space: normal;        /* 原本是 nowrap */
  text-align: center;
  line-height: 1.3;
}

.caret-icon { margin-left: 6px; }   /* 原本靠 flex gap，改 margin */
選單置中位置改由「剩餘空間」決定，所以 logo 與右側按鈕都不會被壓縮；@media (max-width: 1600px) 那段的縮排／縮字級規則不必動，它們只是更早一階的保險。
